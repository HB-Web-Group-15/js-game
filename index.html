How to Play

Game rules

The objective of the game is to fill a 9×9 grid with digits so that each column, each row, and each of the nine 3×3 subgrids that compose the grid (also called "boxes", "blocks", or "regions") contains all of the digits from 1 to 9.

Game controls

To write a number, first select the cell you want to input the number in, then write a number by either pressing a key or clicking a coresponding number. Enter the note mode by clicking the pecil icon or pressing "N" key on the keyboard. Check if current solution is correct by clicking the check mark icon or pressing "Enter" on the keyboard. Erase value in selected cell by clicking on the Eraser icon or pressing "Backspace" or "Delete" keys on the keyboard. Remove all inputed values by clicking on the reset icon or pressing "Shift+R" on the keyboard. Pause button freezes the timer and hides the board. Difficulty selector lets you choose difficulty for the next game. New Game button generates a new sudoku puzzle based on difficulty selected.

Settings tab

In the settings tab you can set the name that will be visible on the scoreboard, you can also choose if you want to see the timer or not, the last option in settings tab lets you choose what tipe of feedback on your mistakes you get after clicking check result with the incorrect solution on the board.

Scoreboard tab

In the scoreboard tab you can see rankings of players, their names, their times and difficulty they played on
